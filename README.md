# homebrew-reditch

[Reditch](https://github.com/TetsuyaNegishi/reditch) の Homebrew Cask 配布用tapです。

## インストール

```bash
brew install --cask tetsuyanegishi/reditch/reditch
```

または事前にtapしてから:

```bash
brew tap tetsuyanegishi/reditch
brew install --cask reditch
```

## アンインストール

```bash
brew uninstall --cask reditch
```
